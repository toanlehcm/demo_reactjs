## 🔴 Critical Issues (Phải sửa ngay)

### 1. ⚠️ NGUY HIỂM: API Token bị lộ trong file .env

- **File:** [.env](file:///Users/toanle/Documents/DEV/FESources/demo_reactjs/.env)
- **Triệu chứng:** File `.env` chứa 2 Figma Access Token dạng plain text:
  ```
  FIGMA_ACCESS_TOKEN=figd_mk--kFqKClGcQwm-...
  FIGMA_ACCESS_TOKEN_TOANLE=figd_MzeN4z5Fix...
  ```
- **Nguy hiểm gì?** Mặc dù `.env` đã có trong `.gitignore` (tốt! ✅), nhưng nếu file này đã từng được commit trước đó, token đã bị lộ trong Git history. Bất kỳ ai clone repo đều có thể dùng token này để truy cập Figma account của anh.
- **Cách sửa:**
  1. **Revoke ngay** 2 token này trên Figma (Settings → Personal Access Tokens)
  2. Tạo token mới
  3. Kiểm tra Git history: `git log --all --full-history -- .env`
  4. Nếu từng commit, dùng `git filter-branch` hoặc BFG Repo Cleaner để xóa khỏi history

### 2. ⚠️ NGUY HIỂM: Form Login không có bảo mật cơ bản

- **File:** [LoginForm.jsx](file:///Users/toanle/Documents/DEV/FESources/demo_reactjs/src/components/login-page/LoginForm.jsx)
- **Triệu chứng:**
  - Form login **không có `onSubmit` handler** → form gửi request mặc định (reload page)
  - **Không có validation** cho username/password
  - **Không có rate limiting** hay captcha
  - **Không có CSRF protection**
- **Nguy hiểm gì?** Nếu deploy lên production, form này hoàn toàn không hoạt động vì không có xử lý submit. Nếu sau này thêm API call mà không có validation, hacker có thể brute-force login liên tục.
- **Cách sửa:**
  1. Thêm `onSubmit` handler với `e.preventDefault()`
  2. Thêm validation (dùng Formik/Yup đã có trong project)
  3. Thêm rate limiting phía server khi deploy thật

### 5. Render 10,000 items không có Virtualization

- **File:** [fakeLogs.js](file:///Users/toanle/Documents/DEV/FESources/demo_reactjs/src/components/ActivityLists/fakeLogs.js)
- **Triệu chứng:** Tạo mảng 10,000 items, mỗi item có 2 ảnh ngoài (avatar + preview). `ActivityListNoOptimization` render tất cả cùng lúc.
- **Nguy hiểm gì?** 
  - 20,000 HTTP requests cho ảnh (10K × 2)
  - DOM chứa 10,000 nodes → browser lag/crash
  - Không có lazy loading, không có virtualization
- **Cách sửa:** Dùng `react-window` hoặc `react-virtuoso` để chỉ render items trên màn hình. Thêm lazy loading cho images. *(Ghi chú: `ActivityList.jsx` có CSS `content-visibility` là bước đi đúng hướng!)*
